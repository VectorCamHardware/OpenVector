Build VectorCam

An open-source guide to building VectorCam — the most intelligent solution in malaria surveillance.

VectorCam's answer to malaria surveillance pairs an ordinary smartphone with a small magnifying lens, a simple circuit, and an AI-powered app to read a mosquito's species, sex, and abdomen status in seconds. This webpage serves as a one-stop platform, documenting everything required to build a VectorCam for your community: from sourcing parts through field deployment.

STL Files

Print files come straight from the OpenVector repository's stl/ folder. Every part fits all compatible phones. Each file is a print plate; print one of each to build a device. Print the Transparent Diffuser in transparent PETG and all other parts in white PETG.
