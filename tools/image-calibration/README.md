# Image Quality Test

A web page that checks a photo taken with a VectorCam device, using a ChArUco calibration board, and reports measures such as focus, exposure and white balance.

Open it at **https://vectorcamhardware.github.io/OpenVector/tools/image-calibration/**. The page downloads its image-analysis library (about 13 MB) the first time it is used.

This tool was previously a separate repository, `ImageCalibration`. Its history is kept here.
